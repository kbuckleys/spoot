SPOOT AUDIT CHANGELOG

FIXES
- Fixed a crash that could happen when shutting down after the engine had
  died several times.
- The single-instance socket now lives in your private runtime directory, so
  another user can't block spoot from starting.
- Titles containing < or > (like <Untitled>) are no longer blanked or cut off.
- Play, pause, skip and seek now show the new state straight away instead of
  up to a second later.
- Covers that time out are retried instead of being written off for 6 hours.
- The cover index and cache files no longer lose entries when the engine and
  background jobs write them at the same time.
- Trail History now tells apart different podcasts, episodes and settings
  pages.
- "Signed in" now requires a token file you can actually log in with.
- If the engine fails a request, the UI no longer gets stuck (invisible panel,
  setup that can't be re-run, blank start).
- Replies to navigation you've already moved past are ignored.
- Prompts opened from a card (e.g. Rename Playlist) now submit and cancel
  correctly.
- The hidden panel no longer takes clicks while Listen is running.
- Detail sheets no longer overlap rows when a value wraps.
- Pressing only a modifier key, or holding a key down, no longer closes
  overlays.
- Authorise Playback no longer freezes the app for up to about 3 minutes.
- The "network is down" check is shared across the engine and background jobs.
- Background writes now send their request body; before, it was silently
  dropped.

SECURITY
- The request log hides login tokens and is readable only by you.
- The curl fallback no longer puts your access token on its command line.
- The perl login fallback only listens on 127.0.0.1.
- The playerctl fallback accepts only known commands.
- Login secrets are now generated inside the app instead of by running
  openssl.

PERFORMANCE
- Episode progress, "Liked" lookups and "is this program installed" checks are
  cached.
- Covers that are already on disk, or known to be missing, aren't downloaded
  again.
- Background jobs no longer repeat folder creation and process cleanup every
  time they start.
- The session file is only rewritten when it actually changes, and always
  completely.
- Lists are filled in one step instead of row by row.
- The progress bar, lyrics sync, animations and blinking cursor do less work,
  especially while the panel is hidden.
- Cover grids remember the last two grids, so going into an item and back is
  faster.
- A batch of covers queued just as the background downloader was finishing is
  no longer left waiting for the next redraw.

CLEANUP
- Removed dead code and unused variables.
- Removed comments about the old rofi version or code that no longer exists,
  keeping the explanations of how things work now.
- Moved comments that were sitting above the wrong function.
- Merged repeated QML code into helpers (trail cutting, sending a step, one
  Shell check).
- The in-app keybind list now matches the actual keys.

INSTALLER AND DOCS
- setup:
  - Builds in Release mode and requires Qt 6.5+ and LayerShellQt 6.1+.
  - Installs Lua development headers on every distro.
  - Checks for the QML modules and Qt Wayland plugin the window needs.
  - Refuses to run under sudo, and exits cleanly if interrupted.
  - Fixes several smaller issues with fonts, the desktop entry and choosing
    packages.
- README: corrected keybinds and dependency list (now grouped as required,
  optional and fallback-only), file locations, and a new Development section.
- Test scripts: clean up after themselves, no longer kill a running session
  unless asked, and the smoke test counts its own checks.
- Added a .gitignore, made the scripts executable, and corrected the notes in
  tsan.supp.
